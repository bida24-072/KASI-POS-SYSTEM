# 🏪 Kasi POS System

A fast, modern, browser-based Point of Sale system for Botswana retail shops. Built by **Digital Innovations** — works offline, saves locally, prints real receipts.

![Status](https://img.shields.io/badge/Status-Live-success)
![Made in Botswana](https://img.shields.io/badge/Made%20in-Botswana%20🇧🇼-amber)

## ✨ Features

- 🛒 **Main POS screen** — tap products to add to cart
- 🏷️ **Category filters** — drinks, food, snacks, airtime, household
- 🔍 **Live search** — find products instantly
- 💰 **Automatic VAT calculation** — 12% Botswana rate
- 🧾 **Print-ready receipts** — business info, items, VAT, total
- 📦 **Inventory manager** — add, edit, delete products
- 📊 **Sales dashboard** — revenue, transactions, top products
- 📥 **CSV export** — download all sales for accounting
- 💾 **Persistent storage** — everything saves to localStorage
- 📱 **Mobile responsive** — works on tablets and phones
- ⚡ **Zero dependencies** — pure HTML, CSS, JavaScript
- 🚫 **Works offline** — no internet needed after first load

## 🎯 How It Works

### First Time
- 20 default products load automatically
- Categories and search work instantly
- Tap any product to add it to cart

### Complete a Sale
1. Add products to cart
2. Tap **Complete Sale**
3. A printable receipt appears
4. Click **Print** — or **Close** to finish
5. Stock decrements automatically
6. Sale records to the dashboard

### Manage Inventory
1. Go to **Inventory**
2. Click **Add Product**
3. Or edit/delete any existing product

### See the Data
1. Go to **Dashboard**
2. View revenue, top sellers, recent sales
3. Click **Export CSV** for accounting
